# סוכן AI לסיכומי פגישות

תכנון של סוכן AI ליועצת מערכות מידע עצמאית. Fireflies.ai מתמלל את הפגישה, והתמלול נשמר אוטומטית בתיקיית הפרויקט ב-Google Drive לפי שם הפרויקט שבנושא הזימון. הסוכן מופעל רק כשנוחת תמלול חדש. הוא מסכם את הפגישה, מנסח מייל ללקוח ומשאיר אותו **בטיוטות ב-Gmail** עד לאישור, בעלות של עד $0.50 לתמלול. השליחה ללקוח ידנית בשלב הזה, והתכנון כבר כולל הרחבה עתידית לשליחה אוטומטית.
