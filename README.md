# סוכן AI לסיכומי פגישות

סוכן AI למנהלי פרויקטים של יישום מערכות מידע, מבוסס על מודל השפה Claude ומופץ דרך Claude Platform. כל מנהל פרויקט מפעיל את הסוכן על התיקיות שלו. Fireflies.ai מתמלל את הפגישה, והסוכן מסכם אותה בשפה מכבדת ועניינית, ומשאיר מייל ללקוח **בתיקיית הטיוטות** עד שמנהל הפרויקט מאשר ושולח. העלות: עד $0.50 לתמלול.
